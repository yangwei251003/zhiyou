# Changelog

All notable changes are documented here. This project uses pre-release semantic versions while the
public-release gates remain incomplete.

## 0.1.0-alpha.1 - 2026-08-31

- Added the encrypted local career-evidence vault and evidence review workflow.
- Added bounded PDF/DOCX/Markdown/text ingestion in a one-shot utility process.
- Added Codex App Server account status, deep interview, job analysis, and evidence-bound tailoring.
- Added ATS-oriented HTML/text resume output with claim-level provenance and approval gates.
- Added Windows lifecycle, persistence, accessibility, Electron E2E, and packaged-app smoke gates.
- Published the first unsigned Windows x64 portable preview.
