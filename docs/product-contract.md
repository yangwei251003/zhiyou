# Product contract

## North-star outcome

A student or early-career switcher can move from raw materials to a verified, job-specific,
application-ready package without inventing facts and without giving an AI permission to act on
their behalf.

## Core language

- Use **evidence coverage**, never “hire probability”.
- Use **parse compatibility**, never “guaranteed ATS pass”.
- Use **proposal**, never “fact”, until the user verifies it.
- Use **authorized action**, never “automatic send”, for external writes.
- Use **Codex connection**, never “BossHunter account”, for OpenAI authentication.

## Non-negotiable user journeys

1. Import materials, review extracted proposals, and verify or dispute each claim.
2. Continue a resumable evidence interview that asks only the highest-value unanswered question.
3. Paste or collect a job and see requirements mapped to verified evidence, unknowns, and real gaps.
4. Generate a resume whose every claim links to immutable evidence and survives plain-text parsing.
5. Review the exact target, message, and attachment before any platform action.
6. Recover from crashes or unknown platform outcomes without duplicate sends.
7. Export or delete all local data without hidden copies in logs or backups.

## Deferred beyond 1.0

Cloud sync, multi-user workspaces, mobile clients, unattended batch applications, CAPTCHA bypass,
fingerprint evasion, vector databases, video interview analysis, and a free-form graphic resume
canvas are deliberately excluded.
