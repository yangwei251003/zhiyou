# BossHunter Next v0.1.0-alpha.1

This is an **unsigned Windows x64 evaluation preview**, not a stable public release.

## What you can try

- Build a locally encrypted career evidence vault from PDF, DOCX, Markdown, and text files.
- Review AI-proposed facts before they become part of your profile.
- Connect an independently installed and authenticated Codex App Server on supported Windows hosts.
- Compare verified evidence with a pasted job description and create a tailored resume draft.
- Export ATS-oriented text or single-column HTML after every changed claim is approved.

## Download and verify

Download `BossHunter-Next-0.1.0-alpha.1-windows-x64.zip` and `SHA256SUMS.txt` from this release.
Verify the SHA-256 value, extract the whole archive, then launch `BossHunter-Next.exe`. The archive
is portable and does not install an auto-updater.

Because this preview is not code-signed, Windows SmartScreen may warn or block it. Do not bypass an
organizational policy. If you cannot verify the hash or do not accept the unsigned-preview risk,
build from the frozen source checkout instead.

## Important limits

- OCR, native PDF/DOCX export, encrypted backup/restore, signed install/update, and full fact
  dispute/delete/merge UI are not included.
- Recruitment-platform automation and writes remain disabled.
- The private-alpha broker is not the signed reproducible native broker required for a stable
  release.
- Product name, privacy, Codex distribution, dependency, and platform-term reviews remain open.
- No real resume or personal document should be attached to a GitHub issue.

Read `README.md`, `SECURITY.md`, `LEGAL.md`, and `docs/threat-model.md` before evaluation.
